# Texas Poker

一个用 Godot 4.6 开发的数字版德州扑克游戏。

## 概述

遵循标准德州扑克规则，支持盲注、下注轮次、公共牌和手牌排名。包含基本 AI 对手、交互式 UI、筹码下注和游戏结果结算。

## 开始

打开 Godot 4.6，导入项目，运行主场景 `main.tscn` 即可。

## 项目结构

```
Assets/       — 图标等资源文件
Scripts/      — GDScript 游戏逻辑脚本
scenes/       — Godot 场景文件（.tscn）
docs/         — 架构说明、开发任务等文档
```

## 技术栈

- **引擎**: Godot 4.6
- **脚本**: GDScript
- **渲染**: GL Compatibility
